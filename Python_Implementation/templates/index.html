LZW Compression

Lempel-Ziv-Welch (LZW) is a dictionary-based algorithm. Instead of analyzing character frequencies, it looks for repeating patterns in the data stream.

As LZW reads the data, it builds a dictionary on the fly. When it sees a repeating word or sequence (like "APPLE"), it completely removes that string and replaces it with a single, unique integer code. This dramatically shrinks files containing repetitive text.

Huffman Coding

Huffman is an entropy-based algorithm. It analyzes the exact frequency of every byte and builds a mathematical binary tree to minimize bits.

Traditional encodings use a fixed 8 bits for every character. Huffman shatters this limitation: it assigns the shortest possible binary codes to the most frequent characters, and longer codes to rare ones. The result is a mathematically proven absolute minimum bitstream.

Frequency Based Bit-Assignment
// Frequent Characters (Shortest Bits)
'E' (Freq: 45) → 0 (1 bit)
'T' (Freq: 30) → 10 (2 bits)

// Rare Characters (Longer Bits)
'Z' (Freq: 1) → 1110 (4 bits)
'X' (Freq: 1) → 1111 (4 bits)

Phase I: LZW Pattern Mapping

As data passes through LZW, it dynamically builds a dictionary. Repeating sequences like "BEEP " are reduced to single abstract integer codes. Sequence redundancy is mathematically destroyed.

Dictionary Output Array:
[66, 69, 69, 80, 256, 79, 79, 259]
3

Phase II: Huffman Bit Minimization

Next, Huffman consumes those exact LZW integers. It calculates their overall frequency and builds a binary tree. The most frequently produced LZW codes now get the absolute shortest bit lengths.

Variable-Length Bits Assigned:
Token 256 → '01' | Token 69 → '10'

The True Synergy

By chaining them, LZW handles macro-patterns (words/phrases) and Huffman handles micro-efficiency (raw individual bits). The output is a highly compacted binary payload.
